================================================================================
2. 數值精度轉換
================================================================================

所有 PID 參數 (Kp, Ki, Kd) 使用 100 倍精度縮放:

  寄存器值 = 實際值 × 100
  實際值   = 寄存器值 ÷ 100

範例:
  - Kp = 15.0  → 寄存器值 = 1500
  - Ki = 0.8   → 寄存器值 = 80
  - Kd = 2.5   → 寄存器值 = 250

精度: 0.01 (寄存器值最小變化 1 = 實際值變化 0.01)
寄存器範圍: 0 - 65535 (16-bit 無符號整數)
實際值範圍: 0.00 - 655.35

================================================================================
3. HMI 設定操作步驟
================================================================================

3.1 修改 PID 參數
─────────────────────────────────────────────────────────────────────────────
步驟 1: 計算寄存器值
       實際值 = 使用者設定值 (例如 Kp = 20.5)
       寄存器值 = 20.5 × 100 = 2050

步驟 2: 寫入寄存器
       Modbus Function Code: 0x06 (Write Single Register)
       寄存器地址: 見上表 (例如 LS80-1 Kp = 45501)
       寄存器值: 2050

步驟 3: 驗證結果
       立即生效,無需重啟控制邏輯
       系統會自動檢查參數合理性並限制在有效範圍內

3.2 一鍵恢復出廠預設值
─────────────────────────────────────────────────────────────────────────────
步驟 1: 寫入恢復標誌
       Modbus Function Code: 0x06 (Write Single Register)
       寄存器地址:
         - LS80-1: 45900
         - LS80-2: 45901
         - LS80-3: 45902
       寄存器值: 1

步驟 2: 等待系統執行恢復
       系統檢測到 0→1 邊緣觸發
       自動寫入預設值到 Kp, Ki, Kd 寄存器
       自動清零恢復標誌 (寫回 0)

步驟 3: 驗證結果
       讀取 Kp, Ki, Kd 寄存器確認已恢復為預設值

================================================================================
4. 參數調整指南
================================================================================

4.1 Kp (比例增益)
─────────────────────────────────────────────────────────────────────────────
功能: 快速響應誤差變化
效果:
  - 增大 Kp: 響應速度加快,但可能導致超調或震盪
  - 減小 Kp: 響應速度變慢,但更穩定

調整建議:
  - 溫度控制: 從 15.0 開始,步進 1.0 調整
  - 壓力控制: 從 2.5 開始,步進 0.5 調整
  - 流量控制: 從 2.5 開始,步進 0.5 調整

4.2 Ki (積分增益)
─────────────────────────────────────────────────────────────────────────────
功能: 消除穩態誤差,累積歷史誤差
效果:
  - 增大 Ki: 消除穩態誤差更快,但可能導致積分飽和或超調
  - 減小 Ki: 穩態誤差消除較慢,但系統更穩定

調整建議:
  - 溫度控制: 從 0.8 開始,步進 0.1 調整
  - 壓力控制: 從 0.4 開始,步進 0.05 調整
  - 流量控制: 從 0.4 開始,步進 0.05 調整

4.3 Kd (微分增益)
─────────────────────────────────────────────────────────────────────────────
功能: 抑制超調,阻尼震盪
效果:
  - 增大 Kd: 超調減少,阻尼增強,但對雜訊敏感
  - 減小 Kd: 對雜訊不敏感,但可能出現超調

調整建議:
  - 溫度控制: 從 2.5 開始,步進 0.5 調整
  - 壓力控制: 從 0.8 開始,步進 0.1 調整
  - 流量控制: 從 0.8 開始,步進 0.1 調整

================================================================================
5. 系統行為說明
================================================================================

5.1 參數生效方式
─────────────────────────────────────────────────────────────────────────────
- 即時生效: HMI 修改寄存器後,下一個控制週期立即應用新參數
- 無需重啟: 不需要停用/啟用控制邏輯
- 斷電保持: 參數存儲在非易失性記憶體,斷電後仍保留

5.2 參數合理性檢查
─────────────────────────────────────────────────────────────────────────────
系統每個控制週期會檢查參數合理性:

LS80-1 溫度控制:
  - Kp: 1.0 - 50.0  (超出範圍自動限制為邊界值)
  - Ki: 0.1 - 5.0
  - Kd: 0.0 - 10.0

LS80-2 壓力控制 & LS80-3 流量控制:
  - Kp: 0.5 - 10.0
  - Ki: 0.1 - 2.0
  - Kd: 0.0 - 5.0

超出範圍時:
  - 系統記錄警告日誌
  - 自動限制參數為邊界值
  - 繼續運行,不會停機

5.3 與自適應調整的關係
─────────────────────────────────────────────────────────────────────────────
LS80-1 溫度控制具有自適應調整功能:
  - HMI 設定的 PID 參數作為基準值
  - 系統根據誤差大小動態微調參數
  - 大誤差 (>2°C): 增加 Kp,減少 Ki (快速響應)
  - 小誤差 (<0.2°C): 減少 Kp,增加 Ki (提高精度)
  - 自適應調整不會改變寄存器值,只修改運行時參數

LS80-2 和 LS80-3 無自適應調整功能,使用固定參數

================================================================================
6. 故障排除
================================================================================

6.1 參數無法寫入
─────────────────────────────────────────────────────────────────────────────
症狀: HMI 寫入寄存器後,讀回的值仍然是舊值

可能原因:
  1. Modbus 通訊失敗
     → 檢查 Modbus 連線狀態
     → 確認寄存器地址正確

  2. 寄存器權限錯誤
     → 確認使用 Holding Register (可讀寫)
     → 確認 Function Code 為 0x06 或 0x10

6.2 參數修改後系統不穩定
─────────────────────────────────────────────────────────────────────────────
症狀: 修改 PID 參數後出現震盪、超調或失控

處理步驟:
  1. 立即使用一鍵恢復功能恢復預設值
  2. 檢查修改的參數是否過大或過小
  3. 使用小步進逐步調整參數
  4. 記錄每次調整的效果,找出最佳值

6.3 恢復預設值功能無效
─────────────────────────────────────────────────────────────────────────────
症狀: 寫入恢復標誌 (值 = 1) 後,PID 參數未變化

可能原因:
  1. 控制邏輯未啟用
     → 確認 REG_CONTROL_LOGIC_X_ENABLE = 1

  2. 邊緣觸發未成功
     → 確保恢復標誌從 0 變為 1
     → 若已為 1,先寫入 0,再寫入 1

  3. 系統繁忙
     → 等待 1-2 秒後再次檢查寄存器值

================================================================================
7. 注意事項
================================================================================

1. 安全警告
   - PID 參數錯誤設定可能導致系統震盪、失控或設備損壞
   - 修改參數前請備份當前值
   - 建議在測試環境先驗證參數效果

2. 建議操作
   - 修改參數時一次只調整一個參數
   - 使用小步進逐步調整
   - 每次調整後觀察系統響應至少 5 分鐘
   - 記錄調整歷史以便回溯

3. 技術支援
   - 如需專業調參服務,請聯繫技術支援團隊
   - 提供完整的系統運行日誌有助於問題診斷
